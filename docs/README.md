# Tài liệu Sáng Kiến Công Nghệ

- `bao_cao_sang_kien_cong_nghe.tex`: nguồn báo cáo kỹ thuật. Trang đầu lấy trực tiếp từ trang 1 của `vdt_report_sang_kien_cong_nghe.pdf`.
- `slides.tex`: nguồn bộ slide 5 trang, dùng logo từ PDF bìa mới.
- `vdt_report_sang_kien_cong_nghe.pdf`: PDF template đã đổi tên đề tài và email.
- `vdt_report_template.pdf`: template gốc để đối chiếu.
- `template.tex`: bản sao nguồn báo cáo để giữ tên file template trước đó.

Biên dịch từ thư mục này bằng `pdflatex bao_cao_sang_kien_cong_nghe.tex` (chạy hai lần để cập nhật mục lục) và `pdflatex slides.tex`. Cần cài các gói LaTeX hỗ trợ tiếng Việt, Beamer, TikZ và `pdfpages`.
